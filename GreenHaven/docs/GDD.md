# Green Haven — Game Design Document

Версия документа: 0.2 (PHASE 0–6, этап «Домашний сад»)

## 1. Обзор

| Параметр | Значение |
|---|---|
| Жанр | Cozy Farming Simulator · Idle Management · Economic Simulation |
| Платформа | Android (ландшафт), десктоп — для разработки |
| Движок | Godot 4.5+ (GDScript), рендерер Compatibility |
| Стиль | Изометрический pixel art, тайл 32×16 |
| Режим | Одиночный, полностью офлайн |
| Время | Hybrid Real-Time: процессы идут по реальным часам, в т.ч. при закрытой игре |
| Язык | Русский (основной), архитектура готова к локализации (EN подготовлен) |

## 2. Концепция

Игрок начинает с маленькой домашней гидропонной фермы в уютной комнате и шаг за шагом
превращает её в агропромышленное предприятие. Главное ощущение — спокойный, постоянный
рост: от нескольких лотков микрозелени до автоматизированных производственных цепочек.

Принципы:

* **Нет наказаний за отсутствие.** Растения растут при закрытом приложении, созревший
  урожай не портится, нет «энергии» и обязательных ежедневных входов.
* **Всё связано.** Каждая покупка меняет реальные параметры производства.
* **Масштабирование.** Каждый этап добавляет новый уровень управления, а не просто цифры.

## 3. Основной игровой цикл

```
Купить семена → Посадить → Ждать (реальное время) → Собрать → Склад
      ↑                                                         ↓
Расширение ← Оборудование ← Прибыль ← Продажа ←─────────────────┘
      ↓
Опыт → Уровень → Новые культуры / навыки
```

## 4. Этапы прогрессии

| # | Этап | Содержание | Статус |
|---|---|---|---|
| 1 | Home Garden | Комната, гидропонные стеллажи, 8 культур, базовое оборудование | **в разработке (v0.x)** |
| 2 | Smart Hydroponics | Автоматизация, датчики, больше стеллажей | архитектурный задел |
| 3 | Greenhouse | Первая теплица, почвенные грядки | архитектурный задел |
| 4 | Small Farm | Земельные участки, техника | архитектурный задел |
| 5 | Livestock | Животноводство | архитектурный задел |
| 6 | Agricultural Enterprise | Цепочки переработки, контракты | архитектурный задел |

Этапы перечислены в `GameManager.Stage`; все данные (комнаты, растения, оборудование)
описываются ресурсами, поэтому новый этап = новые данные + новые модули, без
переписывания существующих.

## 5. Мир (реализовано в PHASE 1)

* Изометрическая комната домашней фермы 8×7 клеток: деревянный пол, ковёр, две задние
  стены с обоями и деревянными панелями, окно с солнечным лучом и пылинками, постер.
* Объекты: 2 гидропонных стеллажа, ящик для хранения, рабочий стол, монстера,
  короб для продажи. Все — данные (`resources/placeables/*.tres`).
* Камера: плавное перемещение, инерция, масштаб жестом/колесом, pixel-perfect уровни
  масштаба, ограничение по границам комнаты.
* Взаимодействие: касание — выбор и информационная панель; удержание — перетаскивание
  предмета по сетке с подсветкой допустимой/недопустимой клетки; кнопка «Переместить»
  как альтернатива удержанию.

## 6. Растениеводство (реализовано)

8 культур: микрозелень, салат, базилик, шпинат, руккола, редис, клубника, помидоры.
У каждой: ID, название, стоимость семян, время роста, урожайность, базовая цена,
категория, 5 спрайтов стадий (семя → прорастание → молодое → взрослое → созревшее).

* `PlantData` (Resource) — статические параметры культуры.
* `PlantInstance` — состояние посадки: `planted_at`, `ready_at`, параметры цикла,
  зафиксированные **в момент посадки** (оборудование, купленное позже, не меняет
  запущенный цикл).
* Стадия вычисляется из `TimeManager.progress(planted_at, ready_at)`; логика отделена
  от визуализации. Одна система для гидропоники, почвы, теплиц и полей
  (тип посадочного места — данные).

Баланс — в [ECONOMY.md](ECONOMY.md).

Взаимодействие: касание стеллажа выбирает его и открывает список мест (посадить /
таймер / собрать); если на стеллаже есть созревшие растения, касание сразу собирает их.

## 7. Реальное время (реализовано)

* Unix-метки; никаких фоновых циклов роста — состояние вычисляется по запросу.
* `TimeManager` отделяет источник времени (`TimeSource`) от расчётов.
* Защита: невалидные метки отбрасываются, перевод часов назад не откатывает
  прогресс и не даёт повторного сбора; оставшееся время никогда не отрицательное.
* Ускорение от оборудования с ограничением максимального бонуса (см. ECONOMY.md).

## 8. Экономика (реализовано)

Монеты; все операции только через `EconomyManager` (`buy_item`, `sell_item`,
`add_coins`, `remove_coins`, `can_afford`), баланс не может стать отрицательным,
учёт доходов/расходов. Инвентарь — `InventoryManager`. Цены централизованы в данных.
Задел: спрос, динамические цены, контракты, репутация, переработка.

## 9. Оборудование (реализовано)

Гидропонный стеллаж, улучшенный стеллаж, LED, улучшенный LED, автополив, резервуар,
контроль pH, автоматическая система питания. У каждого: ID, название, стоимость,
описание, категория, спрайт, функциональный эффект (модификаторы производства).

## 10. Прогрессия персонажа (реализовано)

Уровень, опыт за действия (посадка, сбор, продажа), открытие культур по уровню,
ветки навыков «Агрономия» и «Торговля»; задел под «Технологии», «Механику»,
«Животноводство».

## 11. Сохранения (реализовано)

JSON, версия формата + миграции, валидация, запись через временный файл,
резервная копия, автосохранение при сворачивании (`GameManager.app_paused`).

## 12. UX для Android

Ландшафт (sensor landscape), крупные кнопки (≥ 40 единиц базового разрешения
640×360 ≈ 7–8 мм), всплывающие панели, кнопка «Назад» закрывает верхнюю панель,
корректная обработка сворачивания. Цель — 60 FPS, допустимо 30 FPS.
