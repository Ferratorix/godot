# Тестирование

## Как запускать

```bash
# из каталога GreenHaven/
godot --headless --path . --import                         # первый раз: импорт ассетов
godot --headless --path . -s res://tests/run_tests.gd      # автотесты, код выхода 0/1
# скриншот (нужен дисплей; в CI — xvfb-run):
xvfb-run -a godot --path . -s res://tools/screenshot.gd -- out=/tmp/shot.png select=storage_crate
```

Свой мини-раннер (`tests/run_tests.gd` + `tests/test_case.gd`) — без сторонних зависимостей.
Методы `test_*` в файлах `tests/test_*.gd` находятся автоматически.

### Как проверялись сценарии времени
Через `ManualTimeSource`: «закрытие игры» = сохранение → сдвиг часов → загрузка;
«перезагрузка устройства» для одиночной офлайн-игры эквивалентна закрытию приложения
(состояние только в файле, метки абсолютные); «изменение системного времени» = перевод
источника назад/вперёд.

### Не проверено (требуется устройство)
* Реальные мультитач-жесты, системная кнопка «Назад», вибрация, сворачивание на Android.
* Путь `user://` на Android и сохранность данных при обновлении APK (пакет
  `com.greenhaven.game` должен оставаться неизменным).
* Производительность (FPS, память) на среднем устройстве.

## Исправленные при тестировании ошибки

1. Инфо-панель раскрывалась на всю высоту и была пустой: анимация меняла `position`
   anchored-контрола, пока autowrap-метки ещё вычисляли размер, и неверный размер
   «запекался» в offsets. Решение: анимация только `modulate`/`scale` + минимальная
   ширина у переносимых меток.
2. Камера могла не стать текущей, если в дереве уже была другая Camera2D →
   явный `make_current()`.
3. Символ «◎» отсутствует в шрифте → иконка-спрайт для кнопки «показать комнату».
4. Ящик для хранения был скрыт за стеллажами → перестановка в `home_garden_room.tres`.

v0.2:
5. Объекты комнаты строились дважды; старые узлы жили до конца кадра → немедленное
   удаление + флаг `auto_build`.
7. (v0.3) В canvas_item-шейдере нет `NODE_POSITION_WORLD` → `MODEL_MATRIX`.
8. (v0.3) Тест верхней панели — счётчик монет теперь анимируется, тест ждёт окончания.
6. Скрипт `-s` не видел autoload-ы при компиляции → сценарий скриншота вынесен в
   отдельный файл, загружаемый во время выполнения.
