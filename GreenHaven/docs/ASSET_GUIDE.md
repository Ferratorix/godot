# Руководство по графике

## Геометрия

| Элемент | Размер | Опорная точка |
|---|---|---|
| Тайл пола | 32×16, ромб, линии 2:1 | центр ромба |
| Объект 1×1 | ширина 32, высота произвольная | `texture_anchor = (16, H-8)` — центр ромба основания |
| Срез стены | 16 × (56 + 8) | ставится по ребру клетки (см. `FarmRoom._build_walls`) |
| Стенной декор | наклон 1:2 вдоль стены | вручную в `FarmRoom` |

* Только целочисленные пиксели, без сглаживания и полупрозрачных краёв.
* Фильтр — Nearest (глобально в `project.godot`), mipmaps выключены.
* Свет падает справа (из окна): левые грани темнее, правые светлее.
* Контур — тёплый тёмно-коричневый `#3B2A20`, не чёрный.

## Временные ассеты

Всё в `assets/placeholder/` генерируется `tools/generate_placeholder_art.py` и
**не является финальной графикой**. Замена: положить финальный файл в `assets/sprites/…`
и переключить ссылку в соответствующем `.tres` (код менять не нужно).

| Файл | Где используется |

### Звук (временный)
`tools/generate_placeholder_audio.py` → `assets/placeholder/audio/*.wav` (моно, 22 050 Гц).
Мягкие синусоиды/треугольники, без резких частот. Музыка: 80 BPM, C–Am–F–G, 24 с,
бесшовная петля. Финальная музыка — OGG Vorbis, эффекты — WAV/QOA; громкость эффектов
выровнена на пик −4,4 dBFS, музыки −7 dBFS.

### Растения
* Кадр 12×14, линия грунта на 2 px выше нижнего края (`WorldObject.PLANT_SOIL_OFFSET`).
* Позиции на стеллаже — `PlaceableData.slot_positions` (относительно центра основания).
* Стадии: 0 семена (точки), 1 росток, 2 молодое, 3 взрослое (цветы/зелёные плоды),
  4 созревшее (цвет плода/корнеплода хорошо виден).
